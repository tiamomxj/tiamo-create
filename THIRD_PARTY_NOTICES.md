## Minecraft
NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
"Minecraft" is a trademark of Mojang AB / Microsoft and is used here only to describe what this tool works with.

No game assets are shipped - no code, textures, models, sounds or translations. `scripts/mcbuild/data/<version>/`
contains factual interoperability data: block state lists and registries produced by the game's own report generator,
block tags, per-state physical facts measured by this project's harness (light, collision boxes …), the first game
version of newer blocks, and a neutral level.dat template. Everything visual or textual comes from the player's own
installation at run time: block models and textures from their client jar (or one they explicitly download from
Mojang with `mcb fetch client`), block and biome names from their game's language files.

## Litematica / MaLiLib, Voxy, Bobby (not shipped)
The in-game test uses the player's own Litematica and MaLiLib (by masa and contributors, LGPL-3.0) or copies fetched
from Modrinth on the player's request; they are never redistributed. Voxy caches are read through a small read-only
bridge (`scripts/mcbuild/vendor/atlas/bridge`, part of this project) with the RocksDB JNI library found inside the
player's installed Voxy mod (RocksDB: Apache-2.0 / GPL-2.0). Bobby caches are plain region files read by this
project's own reader.
